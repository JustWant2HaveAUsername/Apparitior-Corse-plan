# 课间穿梭 · 智能课表分配器

HackSHSID 2026 Track 1 的 Python/Tkinter 原型。从单个学生的角度，在完整满足每门课程周课时的前提下，优化走班路程、课前准备和喜好搭配。

## 运行

需要 Python 3.10 或更新版本及标准库 tkinter，无第三方依赖。

```bash
python3 smart_scheduler.py
```

在“课程”页添加或修改课程，在“地点与路程”页填写步行分钟数，在“时间与偏好”页设置晨会、订餐和储物柜位置，然后生成课表。

现有的 `schedule_data.json` 包含 12 门课程，可点击“读取”打开。程序启动时恢复 `schedule_autosave.json`；两个文件独立，读取时会使用所选文件的数据。

## 课程与时间规则

- 周课时以**分钟/周**填写，不再以节数填写。
- 学校作息固定为 7 个时段：08:30–09:30、09:40–10:20、10:30–11:10、11:20–12:05、13:15–14:10、14:20–15:00、15:10–15:50。
- 周一至周四每天 320 分钟，周五最后两节不上课；一周共 1520 分钟、33 个可用时段。课间和午休不计入授课分钟。
- 所有时段完整占用，不拆分、不四舍五入。例如 60 分钟可使用一次第一节；80 分钟可以使用两次 40 分钟时段。
- 普通课程同一天最多一次。“每天最多”是额外上限，不能使普通课程一天重复多次。
- 勾选“两节连上”后，每次必须安排两节相邻课程；不跨午休，不允许单节。80 分钟连堂可以使用第 2–3 节或第 6–7 节。
- 所有课程的周分钟数必须精确相等，不允许重叠或漏排。若分钟数无法组合、课程之间争抢时段或超出容量，程序明确报错。
- 总分钟数不超过 1520 并不保证可排。例如六门各 60 分钟的课程都只能使用第一节，但一周只有五个第一节。
- 每门课程可指定主地点、可选第二地点、准备分钟数、喜爱度和是否需要课前去储物柜。

## 算法

先枚举每门课满足分钟数和每日限制的全部周时段组合，使用回溯搜索寻找互不重叠的完整课表。搜索优先安排可选方案最少的课程；失败会回退重试，不会将两门课写入同一个格子。搜索设有 15 秒时限，超时表示尚未找到答案，不等于证明无解。

找到完整课表后，以模拟退火优化：尝试更换某门课的组合，或交换时长相等的时段。每个候选课表都重新检查课时和连堂约束，最终输出前也会再次验证。

评分为：

```text
移动分钟
+ 60 × 路程来不及的分钟
+ 25 × 课前准备不足的分钟
+ 喜好权重 × 同类喜好相邻次数
```

路程按实际课程之间的可用间隔计算，空课时也提供移动和准备时间。启用晨会、订餐、储物柜时计入相关绕行；连堂第二节沿用同一教室，不重复去储物柜或准备。可选第二地点按到达该课前最后一个途经点的距离选择，这是局部选择，不保证整天路线全局最优。

课时、课程完整性和连堂是硬约束；路程来不及与准备不足使用上述惩罚评分，结果可能仍有不足，应查看指标和警告。

“优化前”是回溯搜索得到的首个完整可行课表，**不是学校实际课表**。优化后的评分保证不高于该基线，启发式优化不保证全局最优。

## 保存与读取

“保存”写入课程、地点、路程矩阵和设置；“读取”恢复这些输入并重新生成课表，不保存某一次优化中的课表格子。

自动保存位于程序目录的 `schedule_autosave.json`。写入先使用临时文件，成功后替换目标，减少写入失败损坏原文件的风险；自动保存失败会显示在状态栏。

旧版只有 `sessions` 的存档会按“节数 × 旧存档的 period_minutes（默认 45）”转换为分钟。若 `lesson_minutes` 已存在且大于零，优先保留它。转换后的分钟数仍须满足当前固定作息；不能组合时会提示调整。

空课程模板也能保存和读取；读取错误不会覆盖当前输入。“导出 CSV”输出生成的周课表和对比指标。

窗口缩放时，长说明自动换行，操作栏和指标区调整布局。左侧输入页、课程列表和右侧课表提供滚动条；课表中的课程名称与地点完整换行显示。周五最后两格不绘制，CSV 对应位置标记“不上课”。

## 验证

```bash
python3 smart_scheduler.py --selftest
python3 -m unittest -v
```

回归测试涵盖：

- 现有 12 门课程、1520 分钟全部排入，逐门核对分钟数，33 个可用时段恰好填满；
- 33 格满课表、周五最后两节禁排、60 分钟单课、80 分钟连堂；
- 单门课分钟数无法组合、各门课能单独排但合并无解；
- 候选组合覆盖整周，不再截断为前 80/200 个；
- JSON 保存/读取按钮回调、连堂和储物柜字段保留、空模板读取；
- 旧版存档迁移、读取失败保留当前数据、写入失败保留原文件；
- 连堂第二节不重复取书。

另做了实际 Tkinter 窗口检查，确认课程列表和课表能绘制；保存/读取流程使用临时文件验证，文件选择对话框在测试中代选路径。

缩放检查覆盖 1000×640、1200×760、1360×880、1600×950 四种窗口尺寸，以及三种分栏宽度，检查全部三个输入页的文字与控件边界和界面回调错误。

测试数据和默认步行时间属于示例，指标不能直接代表学校真实课表的改善。程序只处理一个学生的五天课表，未处理教师冲突、教室容量、固定课程、天气或拥堵。真实比较需要实测路程及现有学校课表。

## 文件

- `smart_scheduler.py`：界面、求解器、数据存取和内置自测。
- `test_scheduler.py`：回归测试。
- `schedule_data.json`：现有 12 门课程输入。
- `schedule_autosave.json`：本地自动保存。
